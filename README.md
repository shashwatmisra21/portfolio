# Shashwat Misra — Personal Portfolio

> **2nd Year B.Tech Undergrad • Problem Solver • Developer**  
> Built with pure **HTML5**, **CSS3**, and **Vanilla JavaScript** (Zero dependencies, Zero frameworks).

---

## 🚀 Features

- **Smooth Typing Animation:** Dynamic role cycler with natural cadence and blinking cursor.
- **Interactive Canvas Network:** Lightweight 60 FPS HTML5 Canvas 2D particle proximity mesh reacting to pointer movements.
- **3D Card Perspective Tilt & Glow:** Mathematical pointer-tracking tilt effect with dynamic radial spotlight illumination.
- **Interactive Terminal Widget:** Retro-modern CLI with custom command parser (`help`, `about`, `skills`, `projects`, `contact`, `theme`, `clear`).
- **Dark & Light Mode:** Dual theme engine with smooth transition classes and `localStorage` persistence.
- **Verified Metrics & Milestones:** Animated viewport counters utilizing cubic easing curves.
- **Mobile Responsive & Accessible:** Semantic HTML, ARIA landmarks, WCAG 2.1 AAA contrast standards, and full touch device support.
- **Respects Accessibility Preferences:** Seamlessly respects `prefers-reduced-motion`.
